    Your database Neon · free

    Algo Hunt keeps your strategies, alerts and paper trades in your own database on Neon. Live data stays in the app, so the free plan is plenty.

    How to get it
    1. Open neon.tech and sign up — it's free.
    2. Create a project. Region: AWS Asia Pacific (Singapore) — the closest to India.
    3. On the project's dashboard press Connect, keep Connection pooling on, and copy the connection string (it starts with postgresql://).
    4. Paste it below and press Test connection.

    Zerodha Kite Connect

    Live prices and candles come from your own Kite Connect app — Algo Hunt only reads data.

    How to get it
    1. Open developers.kite.trade and log in with your Zerodha account.
    2. Press Create new app → type Connect. App name: Algo Hunt.
    3. Redirect URL: http://localhost:3000/zerodhaRedirection — Postback URL: leave empty.
    4. Save. Copy the API key, then press Show API secret and copy it.

    Each trading morning you log in to Kite inside Algo Hunt (Kite resets access around 6 AM) — one click from the top bar.

    A password for Algo Hunt

    On this computer Algo Hunt signs you in by itself. The password protects your data if it's ever opened another way — keep it somewhere safe.

    Telegram alerts optional

    Get every alert on your phone, even when Algo Hunt isn't on screen.

    How to get it
    1. Use your admin's bot token, or make your own bot: open @BotFather in Telegram, send /newbot and follow the steps.
    2. Paste the bot token below.
    3. Optional: your chat ID to get a test message now. People and groups who receive alerts are added later in the app — Settings → Telegram chats → Find chat IDs (each person opens the bot and presses Start first).

    Email alerts optional

    Send alerts by email too, through Resend. Who receives them is set later in the app (Settings).

    How to get it
    1. Open resend.com and sign up.
    2. API Keys → Create API key, copy it (it starts with re_) and paste it below.
